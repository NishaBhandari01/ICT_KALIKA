## About the Project

this is the website rebuild by referencing ICT-kalika old website. this  website  provides information about ICT-club of kalika and events it is conducting.
it provides the basic information related to ICT-club of kalika . This website provides a modern and responsive view to all type of visitors. it provides information the club, ongoing events , past events, memebers etc.

ICT Club of Kalika is a student-led IT club established in 2022 at Kalika Manavgyan Secondary School. The club promotes
technology education, digital literacy, creativity, and innovation among students.
